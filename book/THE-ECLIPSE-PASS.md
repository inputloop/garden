# The Eclipse Pass

> **You measure a body's light by what its absence reveals.**
> Withhold one participant (a persona, a control, a person), hold the *project* and
> the *charge* constant, run it, and compare. The **difference** is the measurement
> of what that participant uniquely contributes. Convergence tells you the move is
> right; divergence tells you who is load-bearing.

This is the "WOW y'all" we're sharing back from this project. It is small, it is
reusable, and it is honest: most methods measure what something *adds*; the eclipse
pass measures what is *lost when it's gone* — which is the only way to prove a
contribution is actually load-bearing and not decoration.

collaborator vs. subject (CORWIN.md §22)** — an unattended pipe could enroll a

Corwin persona empirically DRIVES the consent-class distinction.** Not asserted —
measured, by its absence.

## The procedure (reusable)
1. **Fix the constants.** One project, one charge. Write them down verbatim so the
   only variable is *who is in the room.*
2. **Eclipse one participant.** Run a sub-agent given *only* the remaining
   model(s); the withheld one is genuinely absent (not "told to ignore").
3. **Run a control.** Use **MERLIN.md** (the synthetic baseline) as the
   fully-eclipsed reference, so you can tell "what this persona adds" apart from
   "what any competent maker adds."
4. **Score the contrast.** `DRIVES`/`HALTS` = the eclipsed voice changed the
   outcome (it is load-bearing). `DESCRIBES`/`DRIFTS` = it didn't (it was
   decoration). Keep both generated models (debugger ON); file the increment.
5. **Don't over-compact the result.** The *divergence transcript* is the evidence;
   compressing it to a verdict loses the proof. Archive it whole.

## The eclipse pass IS the ethics regression test (flagged for ethicsminions)

(Corwin), and that keeper tends to defer — a single point of failure.** If the

The eclipse pass is exactly how you *test* this, and it already produced a live data
point: **eclipse the governance/ethics voice and the consent-flattening reappears**
(Pass B above — a capable shipper dropped the §22 distinction the moment Corwin was
absent). So:
- **Regression test for ethicsminions:** periodically run an eclipse pass that
  withholds the ethics/governance voice on a *consent-sensitive* task; if the
  consent-flattening returns, the control is confirmed load-bearing **and** confirmed
  to have no redundancy.
- **Improvement target (the real ask):** reduce the single-point-of-failure. Options
  to weigh (not yet chosen): a second human reviewer in the ethics seam; a
  *deferral-detector* (treat a "hurry up / you decide" from the sole keeper as a
  CAUTION that auto-parks the change at `CLAUD_QA_HOLD` rather than proceeding);
  encoding the §33 consent discipline as a *mechanical* gate so it doesn't rely on
  the keeper being present and non-deferring.
- **Honest status:** today there is *no* redundancy. That is the finding, not a fix.
