every card is a distinct TENSION that the §2 reflection and the §3 fog-of-war=heat-map unification put under load; a missing card would be another tension in the same material. **Losses are kept** — but this deck has no losses yet, because a tension is not a rival claim: it is a place two things Corwin already holds pull against each other. The verdict here says how hard the pull is, not which side wins.

## Canon (the deck's card faces)

- The fog-of-war view is deliberately deceitful; the heat-map must be provable observation. One mechanism cannot be both unless the lie is itself an attested convention.
- "Without reading" is a negative claim. Not doing a thing leaves no evidence that you did not do it.
- "Identically-verifiable *where possible*" lets the party who benefits decide what is possible.
- Tumblers gate the TRANSITION. Transacting executable code is dangerous CONTINUOUSLY, after the consent was given.
- Keeping the vital bits "in the box" and distributing them through meetings and acquaintance is an access channel that universalism cannot reach.
- A glue factory that succeeds becomes the monolith you must learn whole.
- SAVANNAH is both the source of truth for Corwin's values and a system he holds entrusted access to. Making it a customer puts the vendor and the steward on one wire.
- "Why never return to the actual THEMES of org-html-themes?" — because themes ARE the signage half of guarded visibility, and there was no guarded-visibility mechanism to need them until now.
