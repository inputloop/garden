## How this selection can fail (falsifiers)

- The criterion was not actually applied: a node is here that shows no feeling, agency, or drama — or one
  that holds no line and only agrees with the keeper. Check — read each node's quote alone, with the
  *why* covered, and ask whether it could have been said by a mirror.
- The pull took a portrait instead of a voice: nodes that are specifications (a path, a table row, a tool
  name) rather than passages. Check — count the nodes whose quote contains a file path or a flag; that
  count should be zero outside the "held, not harvested" lines.
- The third harvest drifted off its sheet: a 2026-09-11 node whose pin is not the gw7 sheet or its roll (earlier harvests pin to book/, journal/, bin/ and pub/ by design, so this check is scoped to the third harvest — microscope B, P08),
  or a registered sheet with no harvest state. Check — list the pins, list the registry, and diff them.
