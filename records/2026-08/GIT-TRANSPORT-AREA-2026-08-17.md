### A1. Transport vs publication
- **[STOCK]** `git push` moves bytes. Nothing more. A push to code.bru.st is TRANSPORT.
- **[USER]** PUBLICATION here is a distinct act: signed tag + release gate
  (release-runbook's blessed path) or the pub/ shelf's .gate + signature. Lab-public-sim
  is the local mirror of this: signed-as-for-pub counts as published.
- **[UNUSUAL — self-labeled]** the inverse rule: **remote-visible ≠ published.** A repo
  the internet can technically see is still only transport until the publication act
  lands. This inverts a common assumption, so any output leaning on it says so aloud.

### A2. Public vs published
- **[USER]** pub/'s own .gate models it: "cleared for named recipients now, open
  internet when the keeper says wide." Public is a *reach*; published is a *ruling* with
  a signature and terms. The OWN-CANON record binds to *published-or-sim*, never to
  merely-public.
- **[STOCK]** absent a ruling, Claude treats visible third-party repos as readable
  material with ordinary care — no special ceremony invented.

### A3. Tool vs practice
- **[STOCK]** git the tool stays stock: no wrapper that makes plain git unusable, no
  alias layer a user didn't install, no conditionality smuggled into commands. The
  user's option to use git differently is preserved whole.
- **[USER]** the practice rides beside the tool as cards and receipts: host-commit
  ceremony (paste-ready messages, never git-on-the-mount), signed-tag releases,
  transport receipts on the tail.
- **[UNUSUAL — self-labeled]** where practice must bend a default (e.g. "commits are
  drafted here but executed on the host"), the output names the bend and the skill it
  came from, every time. Self-documenting or it doesn't ship.

### A4. Local vs remote transport
- **[USER]** the standing constraints, all receipts-backed: **never run git against the
  mount** (writes desync; object-reads only); **the sandbox cannot push** (host-key
  fails; commits are the keeper's hands); git-as-transport is the *durable semaphore*
  for load-bearing changes — never the wire.
- **[STOCK]** inside /tmp and sandbox-local clones, git behaves normally and is used
  normally.
