Gated agent-skill synthesis

Memory tags become curated, gated, installable Claude agent skills — with a paper trail behind every decision.

It is by will alone I set my mind in motion.

What it is

polygram is a small, standard-library-only packaging and orchestration layer. Notes you keep the Mentat way accumulate tags; polygram reads those tags, scores each candidate at an explainable gate, synthesizes skill skeletons only for the ones that pass, and mints installable bundles. Nothing auto-promotes, and every verdict is written to disk as advice.

Memory-driven

The labels that matter to your work decide what becomes a skill.

Gated

Cheap, deterministic signals; explainable PASS / HOLD / REJECT.

Auditable

A dated advice file behind every gate, mint, and override.

The pipeline

  • memory notes
  • candidates
  • gate
  • advice
  • synthesis
  • dist

A note earns a candidate through tags: an Org-style heading tag (:SKILL:) or an inline hashtag (#shell-tooling). A candidate surfaces once its tag appears in enough notes, or when you flag it explicitly.

The gate

How a candidate is scored.
SignalEffect
Corroborated by two or more notes+2
Explicitly flagged by the operatorsurfaces only (no score)
Well-formed label+1
Overly generic label (misc, …)−2

PASS (≥3) synthesizes · HOLD (≥1) waits for review · REJECT is logged and dropped.

Minting — the build pipeline

polygram dist packages curated skills: aggregate .tar.gz / .zip with a SHA-256 manifest, and per-skill installable .skill bundles — a folder-rooted zip the desktop app installs directly.

export POLYGRAM_SKILLS_SOURCE=~/.claude/skills
./bin/polygram dist --format all

Editor and build cruft (__pycache__, *.pyc, *~, *.tmp, Emacs #autosave#, .git) is excluded from every bundle; the workspace copy wins a name collision. This supersedes a hand-rolled packaging Makefile.

Externs, kept honest

Externs are upstream skill sources you clone in. An extern feeds candidates only through its own memory/ notes — never arbitrary documents in the cloned repo. Freezing pins an extern at a revision so it can't silently churn your skills.

This rule exists because a colour token, #ffcc00, once leaked out of an upstream's diagrams and nearly became a "skill." The quality gate caught it; the policy makes sure it can't happen again.

Quality control

Synthesized skeletons are drafts. polygram passes them through a sub-agent quality-control gate: a skill-builder reviewer and an SRE reviewer judge each one independently, and a skill ships only when both agree it is skill-shaped and sound.

color-theory · shipped

Became a real WCAG contrast tool.

concise · rejected

A preference, not a procedure — stays in memory.

ffcc00 · rejected

Upstream diagram noise, not a skill.

Get started

./bin/polygram init      # create a workspace
./bin/polygram scan      # see candidates from memory
./bin/polygram synth     # gate + synthesize the PASSes
./bin/polygram dist      # mint installable .skill bundles
