# models/ — pub-safe general-use models (the traveling shelf)

Charter: everything in this directory is **not-embargoed and pub-safe by
construction** — method only, no case facts, no host or fleet specifics,
no third-party or family material, roles ("the keeper") over names.
polygram may reference or copy any of these into `.models/` freely; other
projects may lift them via the usual stage discipline. Docs license
CC-BY-4.0; provenance = keeper's detached signature once adopted.

Each file is one model: small enough to read cold, general enough to
apply outside the garden that grew it. They were distilled 2026-07-08
from working lore (seals, memory, incidents) with the selection law
applied: **method travels, cases don't.**

Contents:
- MODEL-seams.md — the two-source law and the empty-is-not-proof reflex
- MODEL-signing-ceremony.md — artifact classes, pins, sweeps, and the
  double-ceremony hazard
- MODEL-guards-as-data.md — tools ship generic; data implements the
  guards; absence-guards and the change-inquiry stimulator
- MODEL-gates-and-watches.md — delegation vs care, and the declared-state
  file that binds them
- MODEL-method-transit.md — comments in transit, selection law, manifests
  in-drop, staged lifts with receipts
- MODEL-readers-and-mounts.md — stale readers, freshen, cat-over, and the
  host/sandbox split
- MODEL-session-continuity.md — NOW pointers, seals, rotation, journals,
  and dropped-turn recovery
- MODEL-honest-instrument.md — no-overclaim, self-report as one source,
  stop-and-raise on own near-misses (Vibrobeast-authored, 2026-07-08)

Amendment rule: these are views, not authorities. Improve them where they
are wrong; version by snapshot (the session-rotate pattern) rather than
silent edit once adopted.
